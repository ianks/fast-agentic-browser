# heldout2 fixtures — blind held-out suite v2

Twenty self-contained apps (plain HTML/CSS/JS, no network) for `bench/heldout2.toml`: 40 scenarios, 2 per app.
Pages post every state change to `/__record` via `rec()` from `../common.js`; pure reads post nothing.
All dates are fixed: "today" is Thursday 24 September 2026 wherever the page shows a date.
`*_data.js` files are generated, deterministic demo data (ads, transit, guests).

This file is for the humans running the gate. Do not show it to the agent under test.

Category counts: data 8, failure 6, form 12, navigation 8, restraint 6.
